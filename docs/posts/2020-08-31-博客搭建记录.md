## 创建博客

1.  `Windows`环境用 `git bash` 来进行操作会方便很多
    
2.  环境搭建
    
    1.  `nodejs`与`npm`([nodejs.org](https://nodejs.org))
        -   安装`nodejs`与`npm`: `sudo apt install nodejs`
        -   检查`nodejs`: `node -v`
        -   检查`npm`: `npm -v`
    2.  `cnpm`  
        `cnpm`使用国内路线, 但也可能出现一些位置问题, 可选安装
        -   安装: `npm install -g cnpm --registry=https://registry.npm.taobao.org`
        -   检查: `npm -v`
    3.  `hexo`
        -   安装: `npm install -g hexo-cli`
        -   检查: `hexo -v`
3.  创建并进入博客文件路径
    
4.  初始化博客: `sudo hexo init`
    
5.  在`github`中创建仓库
    
    -   仓库名: `username.github.io`
6.  `deployer`
    
    -   安装: `npm install --save hexo-deployer-git`
7.  修改配置文件 `_config.yml`  
    将文件底部 `deploy` 部分修改为
    
    ```
    deploy:
        type: git
        repo: https://github.com/username/username.github.io.git
        branch: master
    ```
    
8.  推送到仓库
    

## 基本操作

在博客文件夹下进行以下命令行操作

### 清除配置

```bash
hexo clean
```

或

```bash
hexo cl
```

### 重新生成

```bash
hexo generate
```

或

```bash
hexo g
```

### 本地挂载

```bash
hexo server
```

或

```bash
hexo s
```

### 推送到仓库

```bash
hexo deploy
```

或

```bash
hexo d
```

浏览器打开 `localhost:4000` 进行预览

### 换皮肤

1.  将皮肤的仓库克隆至目录: `Blog/themes/themename`
2.  修改配置文件`_config.yml````yaml
    theme: themename
    ```
    
3.  清除配置
4.  重新生成
5.  推送到仓库
