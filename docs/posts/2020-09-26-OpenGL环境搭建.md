进行Visual Studio的OpenGL开发环境搭建

## 下载必要库

-   `GLFW`
    -   针对`OpenGL`的`C语言`库
    -   下载: [Doenload | GLFW](https://www.glfw.org/download.html)
    -   下载32位版本, 因为64位版本不稳定
-   `GLEW`
    -   用于代替`GLAD`来管理函数指针
    -   下载: [The OpenGL Extension Wrangler Library download | SourceForge.net](https://sourceforge.net/projects/glew/)

## 将项目与库连接

1.  将`GLFW`和`GLEW`解压到一个新文件夹中，文件夹名建议为`OpenGL`, 目录结构如下
    
    ```
    - OpenGL
      - glfw-x.x.x.bin.WIN32
      - glew-x.x.x
    ```
    
2.  使用`Visual Studio`创建项目, 创建一个`.cpp`格式的文件, 比如`main.cpp`
    
3.  设置项目属性
    
    1.  `配置`: `所有配置`
    2.  `平台`: `所有平台`
    3.  `C/C++` -> `常规` -> `附加包含内容` -> `编辑` -> `新行`
        1.  `\OpenGL\glfw-x.x.x.bin.WIN32\include`
        2.  `\OpenGL\glew-x.x.x\include`
    4.  `链接器` -> 常规 -> `附加库目录` -> `编辑` -> `新行`
        1.  `\OpenGL\glfw-x.x.x.bin.WIN32\lib-vc20xx`
        2.  `\OpenGL\glew-x.x.x\lib\Release\Win32`
    5.  `链接器` -> `输入` -> `附加依赖项` -> `编辑`
        1.  `opengl32.lib`
        2.  `glfw3.lib`
        3.  `glew32s.lib`
