使用Docker快速搭建Redis服务

## 步骤

### 搭建Redis服务器

1.  下载: `$ docker pull redis`
2.  启动: `$ docker run -dp 6379:6379 --name redis-server redis`
3.  重启: `$ docker restart redis-server`
